## 1. Обязательные доработки по факту (записал, когда удалишь баги)

- **Supabase (облачная БД)** — подключён и работает. Конфиг `js/supabase-config.js` (`enabled: true`), слой данных `js/db.js`, схема `supabase-schema.sql`. Регистрация: **реальная проверка email через OTP-код** — `DB.sendEmailCode` (`signInWithOtp`), `DB.verifyEmailCode` (`verifyOtp`, type `email`), затем `DB.finishRegistration` (ник + пароль через `updateUser` + insert профиля). **Лимиты Free-плана Supabase:** встроенная почта — **2 письма/час** (мало), OTP-эндпоинт — **360 кодов/час**, повторная отправка — раз в 60 сек. Для промышленного режима — свой SMTP (30 писем/час) или сторонний OTP-сервис. В Supabase НЕ включать «Confirm email» при входе по паролю.
- **Перенос данных на облако (Supabase)** — сделано:
  - **Уведомления** (колокольчик) → таблица `notifications` (`DB.listNotifications/pushNotification/markNotificationsRead/removeNotification`), фолбэк на localStorage.
  - **Комментарии на профилях** → таблица `profile_comments` (`DB.listComments/addComment/updateComment/removeComment`), лайки/дизлайки и редактирование синхронизируются с БД.
  - **Обращения (тикеты)** → таблица `tickets` (`DB.listTickets/createTicket/updateTicket`).
  - **Сервера** → таблица `servers` (`DB.listServers`), магазин берёт сервера и товары из `products`/`servers`.
  - **Банлист** → таблица `bans` (`DB.listBans`) — таблица отображается на bans.html.
  - **Команда** → таблица `team` (`DB.listTeam`), **Префиксы** → таблица `prefixes` (`DB.listPrefixes`) с цветом.
  - Все методы имеют фолбэк на localStorage — сайт не ломается без облака.
  - TODO: RLS для записей уже настроен в `supabase-schema.sql`; выполнить скрипт в SQL Editor, чтобы таблицы создались.
- **Админка** — сделана: страница `admin.html`, доступ по уровням: **1 — хелпер** (только обращения), **2 — администратор** (всё кроме выдачи админки), **3 — создатель** (ещё и уровни админов). Разделы: Уровни админов (только создатель), Сервера, Банлист, Обращения (ответ от «Администрации» + уведомление игроку, закрытие/переоткрытие, фильтр «Активные/Закрытые»), Команда, Правила, Префиксы (с цветом и приоритетом, выдача игроку). Все таблицы — CRUD через `DB.adminUpsert/adminDelete` (Supabase), без облака — локальное хранилище `mc:admin:{таблица}`. Ссылка «Админ-панель» в микро-меню аккаунта.
- **Привилегии в профиле** — `js/player.js` (renderPrivilege): показываются ВСЕ выданные привилегии из `profiles.privileges` (кроме стандартной «Игрок»); если привилегий нет — показывается стандартная «Игрок». `js/players-data.js` теперь тянет профили из Supabase (`DB.findPlayerByName`) с кэшем в localStorage (`mc:db-cache:v2`, TTL 5 мин) — привилегии, скины и баннеры из БД видны на player.html. В БД уже выдана привилегия «Создатель» (BuShiZm, Crystals) с сервером **TechoMagicRPG** и красным цветом `#ff3b3b` — красит имя профиля, надпись и полоску.
